# 五子棋 Gomoku

经典五子棋人机对战游戏，纯前端实现。玩家执黑棋先手，AI 执白棋应对。

## ✨ 功能特性

- **15×15 标准棋盘**：木质纹理风格，SVG 渲染
- **人机对战**：玩家（黑）vs AI（白），黑棋先手
- **禁手规则**：黑棋三三、四四、长连禁手检测，棋盘上以红叉标记禁手点并阻止落子
- **胜负判定**：横、竖、斜四方向五连判定，棋盘满判平局
- **AI 对手**：基于棋型启发式评估（连五/活四/冲四/活三等），兼顾进攻与防守
- **交互功能**：悔棋（撤销最近两步）、重新开始、落子序号显示、最后落子红圈标记
- **AI 思考延迟**：约 0.8 秒，模拟思考过程

## 🛠️ 技术栈

- **React 19** + **TypeScript 7**
- **Vite 8** 构建工具
- **SVG** 棋盘渲染
- 纯前端，无后端、无数据库

## 📖 游戏规则

1. 玩家执黑棋先行，AI 执白棋后行，双方轮流在交叉点落子
2. 任意一方在横、竖、斜任一方向连成 5 子即获胜
3. 黑棋存在禁手（白棋无禁手）：
   - **三三禁手**：一步落子同时形成两个活三
   - **四四禁手**：一步落子同时形成两个四
   - **长连禁手**：一步落子形成 6 子或以上连珠
   - 禁手点不可落子，棋盘上以红叉标记
4. 棋盘下满仍无人五连则为平局

## 🧠 AI 算法说明

AI 采用**启发式棋型评估**算法：

1. 候选点：已有棋子周围 2 格范围内的空位
2. 对每个候选点，分别计算**进攻分**（己方落子后的棋型价值）与**防守分**（对方落子后的威胁价值）
3. 综合得分 = 进攻分 × 1.1 + 防守分
4. 选择得分最高的位置落子

棋型评分权重：

| 棋型 | 分值 |
|------|------|
| 连五 | 100000 |
| 活四 | 10000 |
| 冲四 | 1000 |
| 活三 | 1000 |
| 眠三 | 100 |
| 活二 | 100 |
| 眠二 | 10 |
