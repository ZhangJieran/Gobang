# Proposal

## Why

需要一个可在浏览器中运行的五子棋人机对战游戏，让玩家随时可以与 AI 对手对弈，体验经典五子棋的乐趣。当前项目为空，需要从零搭建完整的游戏应用。

## What Changes

- 搭建 React + TypeScript 前端项目骨架（Vite）
- 实现 15x15 标准棋盘的渲染与交互（落子、悔棋、重新开始）
- 实现五子棋核心规则：胜负判定、禁手检测（三三、四四、长连，仅对黑棋生效）
- 实现棋盘辅助显示：落子序号、最后落子标记、禁手点提示
- 实现 AI 对手：基于棋型启发式评估的落子策略，前端 TypeScript 实现，模拟思考延迟

## Capabilities

### New Capabilities

- `game-board`: 棋盘渲染与交互，包括棋子绘制、落子响应、落子序号显示、最后落子标记、禁手点提示
- `game-rules`: 五子棋规则引擎，包括落子校验、五连胜负判定、黑棋禁手检测（三三/四四/长连）、悔棋与重开的状态管理
- `ai-opponent`: AI 对手逻辑，基于棋型评分的启发式评估选点，模拟思考延迟

### Modified Capabilities

（无，本项目为全新项目）

## Impact

- 新增 React + TypeScript 前端代码（Vite 构建）
- 无后端、无数据库依赖
- 新增浏览器端游戏状态管理与 AI 计算逻辑
